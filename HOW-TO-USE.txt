MEMBER 1 FILES - TASKHUB

HOW TO USE
----------
1. Copy the folders inside this zip into your taskhub project folder.
   Let it overwrite the old files. The folders already match the
   correct paths, so just drop them in C:\xampp\htdocs\taskhub

2. Make sure your .env has these lines:

       APP_TIMEZONE=Asia/Manila
       SESSION_LIFETIME=15

       DB_CONNECTION=mysql
       DB_HOST=127.0.0.1
       DB_PORT=3307
       DB_DATABASE=taskhub
       DB_USERNAME=root
       DB_PASSWORD=

   Change DB_PORT to 3306 if that is your MySQL port.

3. Run these commands:

       php artisan config:clear
       php artisan view:clear
       php artisan route:clear
       php artisan migrate:fresh --seed
       php artisan serve

4. Open http://127.0.0.1:8000
